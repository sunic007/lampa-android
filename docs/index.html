Sunic Apps для Lampa на Android

Telegram-бот, «Продолжить с места», сторож плеера и автоподбор источников — плагином для Lampa на телефоне, планшете и Android TV (например, Lampa BS).

  1. Lampa → Настройки → Расширения → Добавить плагин
  2. Адрес:
https://sunic.stream/sunic.js

Старый адрес https://sunic007.github.io/lampa-android/sunic.js тоже работает.

Перезапустите Lampa — в настройках появится «Sunic Apps». Подробнее, English, O'zbekcha — на GitHub. Вопросы — t.me/sunicapps.

Lampa с Sunic Apps работает и на других платформах: любой Smart TV через Media Station X, браузер, Samsung — sunic.stream.
